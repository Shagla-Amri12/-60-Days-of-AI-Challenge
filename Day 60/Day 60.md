## 💡 Final Capstone Project — PaperMind AI

**PaperMind AI** is an AI-powered PDF Knowledge Assistant that enables users to upload PDF documents and instantly receive:

* 📄 AI-generated TL;DR summaries
* 📝 Detailed document summaries
* 🔍 Key insights and highlights
* 💬 Grounded AI chat that answers questions strictly from the uploaded document
* 🌙 Light & Dark mode support
* 📱 Responsive user interface
* ⚡ Production deployment using React, FastAPI, Gemini AI, Vercel, and Render

This project challenged me to solve real development problems, including API changes, deployment issues, asynchronous performance optimization, CORS configuration, environment management, documentation improvements, and production readiness reviews.
