# Personal AI Playbook – STEM Edition

> **Day 49/60 – ABTalks 60 Days AI Challenge**

# Overview

**Personal AI Playbook – STEM Edition** is a modern, single-page AI productivity workspace that helps students and developers organize, reuse, and improve their AI prompting workflows.

Instead of rewriting prompts every time, this application allows users to build a personal library of reusable AI workflows, create structured prompts with a visual Prompt Builder, and design self-improving prompt loops for consistent, high-quality AI outputs.

# Objective

The goal of this project was to create a centralized AI workspace where prompt engineering becomes a repeatable process rather than a one-time activity. By turning everyday AI interactions into reusable workflows, users can save time, improve consistency, and boost productivity across studying, coding, writing, and research.

# Features

* 📊 Interactive Dashboard
* 📚 Reusable AI Workflow Library
* 🧩 Visual Prompt Builder
* 🔄 Loop Builder for Self-Improving Prompts
* ⭐ Favorites & Custom Workflow Management
* 🔍 Search & Category Filters
* 🌙 Dark/Light Theme
* 💾 Local Storage Support
* 📱 Fully Responsive Premium UI

# Tech Stack

* HTML5
* CSS3
* Vanilla JavaScript
* Local Storage API

# Key Learning

The biggest insight from building this project was that **AI becomes significantly more effective when personal prompting habits are transformed into reusable workflows instead of isolated conversations.**

Creating repeatable systems improves consistency, reduces repetitive work, and allows AI to become a reliable productivity partner rather than just a chatbot.
