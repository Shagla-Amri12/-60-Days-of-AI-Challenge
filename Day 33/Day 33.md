# Day 33 – Media Integrity Analyzer | 60 Days Claude AI Challenge

# Project Overview

For **Day 33** of my **60 Days Claude AI Challenge**, I built **Media Integrity Analyzer**, an interactive web application designed to improve media literacy by helping users identify misleading headlines, emotional manipulation, and biased messaging commonly found in news articles and social media posts.

The application guides users through realistic scenarios where they analyze headlines, detect emotionally charged language, identify exaggeration, evaluate source credibility, and receive personalized feedback with educational explanations.

# Objective

The objective of this project was to explore how digital media influences human decision-making and to build an educational platform that teaches users to think critically before believing or sharing online content.

The project focuses on transforming passive readers into informed consumers by encouraging evidence-based thinking instead of emotionally driven reactions.

# One Surprising Thing I Learned

One of the biggest surprises while building and using the **Media Integrity Analyzer** was realizing **how much a single word can completely change the way a headline is perceived**.

Words like **"secretly," "proves," "stunned,"** or **"they don't want you to know"** instantly create urgency, fear, or curiosity—even when the actual article contains cautious, limited, or inconclusive information. I also learned that emotional manipulation doesn't always rely on false information; it often relies on carefully chosen language that encourages readers to react before they think.

This project reinforced the importance of reading beyond the headline, verifying sources, and recognizing emotional triggers before sharing content online.

This project demonstrates how technology can be used to educate users about misinformation and responsible media consumption.
