# Day 8 – Personal Environmental Health Analyzer

# Project Overview

As part of my **60 Days of Claude AI Challenge**, I built a **Personal Environmental Health Analyzer** using Claude Artifacts.

This dashboard combines environmental indicators such as:

=> Air Quality Index (AQI)
=> PM2.5 and PM10 levels
=> Water Quality Metrics

and translates them into:

=> Health risk assessments
=> Environmental health scores
=> Personalized recommendations
=> Actionable insights for daily decision-making

# Features:

=> Interactive dashboard interface
=> Air quality impact analysis
=> Water quality impact assessment
=> Health risk categorization
=> Personalized recommendations
=> Environmental score visualization
=> Insight-driven report cards

# What Surprised Me Most:

The most surprising part was how quickly Claude helped transform an idea into a functional application.

Instead of only generating code, Claude assisted with:

* Application structure and planning
* Dashboard layout design
* Health scoring logic
* Data organization
* User experience improvements
* Insight and recommendation generation

This made the development process feel more like collaborating with a product-thinking partner rather than simply using a code generator.

# Key Learnings:

=> Effective dashboards prioritize clarity over complexity.
=> Strong prompts produce more structured and scalable solutions.
=> Connecting data to real-world impact increases product value.
=> Iteration and refinement remain important human skills.
=> AI can accelerate development, but thoughtful design drives usability.

# Conclusion:

This project demonstrated how AI can support not only coding but also planning, design, and problem-solving. The experience strengthened my understanding of building data-driven applications and reinforced the importance of combining AI assistance with human judgment and creativity.
