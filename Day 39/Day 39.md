#  PDF Splitter & Merger

# Day 39 of 60 – Claude AI Mastery Challenge

Today, I built **PDF Splitter & Merger**, a browser-based web application that enables users to split and merge PDF documents quickly, securely, and efficiently—all without uploading files to a server. The application performs every operation locally in the browser, ensuring complete privacy while delivering a smooth and interactive user experience.

# Overview

Managing PDF documents is a common task, but many online tools require users to upload sensitive files to external servers. This project solves that problem by providing a secure, fast, and user-friendly solution that processes PDFs entirely on the client side. With an intuitive interface, live page previews, multiple splitting options, and drag-and-drop merging, the application offers a professional document management experience.

# Objective

The primary objective of this project was to create a privacy-first PDF utility that combines powerful document manipulation features with an elegant and responsive user interface. Along the way, I focused on improving my understanding of browser-based file processing, JavaScript libraries, and user experience design.

# Key Features

*  Split PDFs using custom page ranges.
*  Split documents after selected pages.
*  Automatically split PDFs every N pages.
*  Extract only selected pages into a new PDF.
*  Merge multiple PDF files into a single document.
*  Live PDF page thumbnail previews.
*  Drag-and-drop file reordering before merging.
*  Dark Mode support for improved usability.
*  100% local processing with no server uploads.
*  Fast, responsive, and modern interface.

# Tech Stack

* HTML5
* CSS3
* JavaScript (ES6)
* PDF.js
* pdf-lib

# Key Learnings

Building this project helped me understand how browser-based applications can perform complex document operations without relying on backend services. I gained practical experience with PDF rendering, manipulating document pages, managing application state, handling drag-and-drop interactions, and designing a responsive interface that balances functionality with ease of use. This project also reinforced the importance of privacy-focused software by keeping all document processing completely local.

# Feature That Impressed Me the Most

The feature that impressed me the most while building this project was the **combination of live PDF page previews with multiple document splitting methods**. Integrating **PDF.js** for rendering page thumbnails and **pdf-lib** for manipulating PDF files created a seamless workflow where users can visually understand their documents before making changes.

What made this feature especially rewarding was seeing how different splitting techniques—such as **Custom Page Ranges, Split After Pages, Every N Pages, and Extract Selected Pages**—could all work together within a single, intuitive interface. It transformed what is usually a complicated document editing process into something simple, interactive, and user-friendly.

Another aspect that stood out was the application's **100% local processing**. Knowing that users can securely split and merge confidential PDF documents without uploading them to any external server made this project feel both technically impressive and genuinely useful in real-world scenarios.
