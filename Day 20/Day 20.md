#  Day 20/60 — Claude AI Challenge

## Face Puzzle Game 🧩📸

Today I built an interactive **Face Puzzle Game** that transforms a captured image into a playable puzzle experience directly in the browser.

The project focused on combining **camera integration, puzzle logic, drag interactions, and responsive UI design** into a single seamless experience.

# Features:

*  Camera capture with live preview
*  Dynamic puzzle generation (3×3, 4×4, 5×5)
*  Drag & touch gesture controls
*  Real-time timer and move tracking
*  Leaderboard with local score storage
*  Responsive experience across devices

#  Results:

*  **Fastest Completion Time:** **28.64 seconds**
*  **Accuracy:** **100% (All pieces solved correctly)**

# Key Points:

* Implemented image slicing and puzzle piece generation
* Built interactive drag-and-swap mechanics
* Added progress tracking using timers and move counters
* Integrated localStorage for saving best scores
* Designed mobile-friendly gameplay with responsive UI

# Learnings:

* Game development requires balancing **logic + user experience**
* Managing **state updates** becomes critical in interactive applications
* Small UI interactions significantly improve engagement
* Performance and responsiveness matter even in browser-based games
* Building complete projects improves problem-solving and debugging skills
