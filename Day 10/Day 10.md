# Day 10 Portfolio Website

• Built a modern personal portfolio website as part of my 60 Days AI Challenge.

# Objective:

=> To design and develop a modern personal portfolio that represents my skills, projects, learning journey, and personal brand while improving my frontend development and UI design abilities.

# Features:

• Responsive Design
• Dark / Light Mode Toggle
• Smooth Animations
• Interactive UI
• Mobile Friendly Layout
• Tailwind CSS Styling
• Modern Portfolio Sections

# Tech Stack:

• HTML
• Tailwind CSS
• JavaScript

# What I Learned:

While building this portfolio, I learned that personal branding is not only about showing projects — it’s about presenting skills, goals, and identity in a clear and professional way.

# Outcome:

Designed a clean and recruiter-friendly portfolio that represents my journey in AI, Python, and Web Development.
