# Day 17/60 — Claude AI Challenge 
# Vehicle Cost Analysis Dashboard:

# Project Overview:

Built an interactive **Vehicle Cost Analysis Dashboard** using CSV-based analytics to explore fuel economics, maintenance impact, environmental performance, and long-term ownership trends across multiple fuel types.
This project transforms raw vehicle data into a visual dashboard using **HTML, CSS, SVG charts, and analytical calculations** to support data-driven decision making.


# Objective

* Analyze vehicle operating costs across different fuel types
* Compare cost efficiency, maintenance burden, and CO₂ impact
* Evaluate the real-world economics of E85 fuel
* Convert complex data into easy-to-understand visual insights

# Analysis Findings

* Calculated **Average Cost/km**, **CO₂/km**, **Maintenance/km**, and **Refuel Time** by fuel category.
* Compared fuel performance across **Petrol, E85, Diesel, CNG, and EV**.
* Evaluated vehicle age impact using **age buckets (New → Old)**.
* Built break-even analysis and scoring logic for **E85 fuel economics**.
* Designed responsive dashboard visuals using **pure SVG charts**.

# Most Surprising Insight

The biggest surprise from the dataset was that **E85 appeared cheaper at the fuel pump but was not actually cheaper to run per kilometer.**

Although E85 reduced fuel price upfront, lower mileage created a hidden running-cost penalty. This showed that **fuel price alone does not determine affordability — efficiency and usage patterns matter more.**

# How Data Visualization Changed Understanding

Data visualization made the insights immediately visible.

Instead of reading rows of CSV values:

* KPI cards highlighted cost differences instantly
* Fuel comparison charts exposed efficiency trade-offs
* Age trend lines showed ownership cost growth over time
* CO₂ visuals revealed environmental impact clearly
* Score gauges simplified multi-factor evaluation into one decision metric

The dashboard turned raw numbers into patterns that were much easier to interpret.

# Key Learnings

✔ Data storytelling is as important as data calculation
✔ Lower price ≠ lower ownership cost
✔ Visualization improves decision-making speed
✔ Dashboard design can reveal hidden patterns in datasets
✔ Real-world analytics requires balancing cost, sustainability, and usability
