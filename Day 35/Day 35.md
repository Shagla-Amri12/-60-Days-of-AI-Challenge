# Objective

The objective of this project was to strengthen prompt engineering skills by solving interactive software engineering scenarios. The challenge focused on learning how to design clear, structured, and optimized prompts that produce accurate, reliable, and context-aware AI responses while avoiding ambiguity and unnecessary instructions.

#  Overview

**Prompt Puzzle** is an interactive learning game designed to teach the fundamentals of prompt engineering through real-world software engineering tasks. Each scenario presents a practical challenge—such as debugging code, writing commit messages, generating unit tests, refactoring code, or creating documentation—where the goal is to identify, build, or optimize prompts for the best possible AI output.

Rather than simply completing tasks, the game emphasizes understanding *why* certain prompts perform better by comparing weak, optimized, and over-engineered prompts. It provides immediate feedback, helping users improve their ability to communicate effectively with AI.

# Prompt Engineering Concept I Learned

One of the most valuable concepts I learned during this challenge is the importance of **explicit constraints**.

A prompt should not only describe *what* needs to be done but also specify *what should not change*. For example, asking AI to **"refactor the code for readability without changing behavior"** produces much more reliable and predictable results than simply saying **"improve the code."**

This demonstrates that well-defined constraints reduce ambiguity, improve consistency, and help AI generate outputs that closely match the intended objective.
